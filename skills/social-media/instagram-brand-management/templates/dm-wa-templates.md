# DM & WhatsApp Funnel Templates

## DM Auto-Reply Templates

### 1. Harga/Price Inquiry
```
Halo! Terima kasih uda mampir 🏡

Biar kami bisa bantu lebih cepet, boleh tau:
1️⃣ Produk yang mana?
2️⃣ Budget range-nya?
3️⃣ Daerah pengiriman?

Atau langsung cek katalog: 👉 [WA LINK]
Kami respond 1-2 jam di WhatsApp 🙏
```

### 2. Katalog Request
```
Halo! 🏡

Katalog lengkap bisa diakses via WhatsApp:
👉 [WA LINK]

Di sana lo bisa:
✅ Lihat semua koleksi + harga
✅ Tanya detail per produk
✅ Request custom size
✅ Order langsung

Balas "1" = link WA, "2" = rekomendasi produk 👇
```

### 3. Custom Order
```
Custom furniture — spesialti kami! 🪵✨

Kirim info:
📐 Ukuran (PxLxT)
🎨 Finishing warna
📸 Foto referensi (kalau ada)
📍 Daerah pengiriman

Lead time: 2-4 minggu
Harga mulai dari: tergantung material & ukuran
```

### 4. Ongkir/Delivery
```
Pengiriman info:

📍 Jabodetabek: GRATIS order > Rp 3jt
📍 Luar JKT: Via ekspedisi, 3-7 hari

Boleh tau:
- Produk apa?
- Kode pos lo?

Nanti kami compute ongkir + ETA 👍
```

### 5. Follow-Up (Warm Lead)
```
Halo! Uda lihat-lihat produk kami ya? 😊

Sekarang ada:
✅ Free delivery Jabodetabek
✅ Cicilan 0% 3 bulan

Ada yang mau ditanya? Langsung reply! 🙏
```
