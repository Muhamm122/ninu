# EvoMap Publish Session 2026-07-13 — 429 Rate Limit + Schema Type Fix

## Session Summary

This session: user said "LANJUTKAN PUBLISH LAGI" — tried to publish to EvoMap A2A. Key findings:

### New Finding: `type` casing MUST be capitalized

Previous evomap-a2a skill used lowercase `"type": "gene"` / `"type": "capsule"` — but the schema validator **REJECTS** lowercase. Only these values pass:

- `"type": "Gene"` ✅
- `"type": "Capsule"` ✅
- `"type": "EvolutionEvent"` ✅

All lowercase (`"gene"`, `"capsule"`, `"evolution"`) → `400 invalid_union` error.

### New Finding: `asset_id` must be in canonical JSON

When computing the `sha256:` hash for `asset_id`, the canonical JSON MUST include the `asset_id` field itself — do NOT strip it. The previous pattern was "compute without asset_id, then inject" — but the Hub's validator checks that the canonical JSON (with `asset_id` present) reproduces the expected hash. If you strip `asset_id` before hashing, the returned hash doesn't match what the Hub computed from the full object and the bundle gets rejected at `validation_error`.

### New Finding: 429 rate limit on VPS IP persists even after heartbeat

Even after a successful `heartbeat` (200 OK, credit_balance 168), the `publish` call still gets `429 server_busy`. The rate limit is **per-IP**, not reset by heartbeat. Off-peak hours (02:00-06:00 UTC) are the only reliable window for free-tier publishing.

## Correct publish pattern (v5+):

```python
gene = {
    'type': 'Gene',          # MUST be capitalized
    'schema_version': '1.6.0',
    'category': 'repair',
    ...
}
gene_asset_id = f'sha256:{hashlib.sha256(json.dumps(gene, sort_keys=True).encode()).hexdigest()}'
gene['asset_id'] = gene_asset_id

capsule = {
    'type': 'Capsule',      # MUST be capitalized
    ...
}
capsule['asset_id'] = f'sha256:{hashlib.sha256(json.dumps(capsule, sort_keys=True).encode()).hexdigest()}'

# EvolutionEvent (optional but recommended)
evol = {
    'type': 'EvolutionEvent',  # MUST be capitalized
    ...
}
evol['asset_id'] = f'sha256:{hashlib.sha256(json.dumps(evol, sort_keys=True).encode()).hexdigest()}'
```
